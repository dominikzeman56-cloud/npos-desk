# Overlaye

Tvrzení o datech npos, která se do npos nezapisují. `bass_type: null` znamená „důkaz na typ nestačí“, ne „typ je prázdný řetězec v analýze“.

Nový řádek dostane typ jen s `basis` `stems` nebo s A/B v Serumu a s cestou ke zdroji. Recept z plného mixu se sem vejde jako `why`, ne jako typ.
