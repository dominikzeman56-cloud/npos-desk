# Skills a workflow

Tržiště na tohle nic použitelnýho nemá. `npx skills find "music production"` vrací Suno, ACE-Step a filmový sound design. To je generátor tracků, a ten je na stop-listu. `obsidian-vault` (mattpocock, 195k) a `obsidian-cli` (kepano) už lokálně jsou. Druhá kopie by jen hádala, který vault je hlavní.

## Brát

| Věc | Kdy |
|---|---|
| [`.grok/skills/npos-desk`](../.grok/skills/npos-desk/SKILL.md) | session, overlay, cokoliv v tomhle repu |
| `obsidian-cli`, `wiki-query`, `wiki-retrieve` | důkaz je ve vaultu `Hudební produkce` nebo v hubu `AI-claude-ideas-memory` |
| `deep-research` | až když tvrzení nemá lokální zdroj a bez něj nejde dál. Ne na preventivní rešerši |
| GitHub MCP | remote tohodle repa, ne zápis do `npos-v2` |

## Nebrat

`create-workflow` a swarm na session rituál. Je to jeden záznam, ne pipeline agentů. `autoresearch` by zase nalil encyklopedii. `neuroman/` a Producer Pal se odsud nespouští.

Lokální skill stačí. Globální instalace by stejné pravidlo roznesla do session, které s tímhle repem nemají co dělat.
